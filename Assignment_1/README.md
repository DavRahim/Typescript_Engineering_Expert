# TypeScript Assignment

## Overview

This assignment covers core TypeScript concepts through hands-on problem solving and two short technical blog posts written in Bangla.

**Problem-solving topics:**

- Default and optional parameters, handling falsy values (`0`)
- Union types and type narrowing with `typeof`
- `readonly` tuples
- Generics with rest parameters and `keyof` constraints
- Interfaces and immutable array operations
- Classes with `protected` / `private` access modifiers and inheritance
- Async functions and Promises with proper error handling
