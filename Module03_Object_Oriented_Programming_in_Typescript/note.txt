🚀 TypeScript এ Clean Code লেখার হাতিয়ার: Object-Oriented Programming (OOP) এর ৪টি মূল স্তম্ভ (Pillars)

আমরা যারা জাভাস্ক্রিপ্ট বা টাইপস্ক্রিপ্ট নিয়ে নিয়মিত কোডিং করি, তাদের প্রজেক্ট বড় হওয়ার সাথে সাথে কোড ম্যানেজ করা একটা বড় চ্যালেঞ্জ হয়ে দাঁড়ায়। কীভাবে কোডকে আরও বেশি সিকিউর, রিডেবল এবং মেইনটেইনেবল করা যায়—তার সবচেয়ে চমৎকার সমাধান হলো OOP (Object-Oriented Programming)।

টাইপস্ক্রিপ্টে OOP-এর ৪টি কোর পিলার (Pillars) খুব সহজ কোড এবং রিয়েল-লাইফ উদাহরণসহ নিচে সুন্দরভাবে সাজিয়ে দেওয়া হলো । আশা করি জুনিয়র থেকে শুরু করে সবারই দারুণ কাজে লাগবে!

১. Encapsulation (এনক্যাপসুলেশন - ডেটা সিকিউরিটি ও হাইডিং)
"বাইরের দুনিয়া থেকে ডেটাকে নিরাপদ রাখা!"

এনক্যাপসুলেশন হলো ডেটা (প্রপার্টি) এবং মেথডগুলোকে একটি সিঙ্গেল ইউনিটের (ক্লাসের) ভেতর আবদ্ধ করে রাখা। এখানে private বা protected মডিফায়ার ব্যবহার করে ক্লাসের বাইরের কেউ যেন হুট করে সংবেদনশীল ডেটা পরিবর্তন করতে না পারে, তা নিশ্চিত করা হয়।
class BankAccount {
// private প্রপার্টি বাইরে থেকে সরাসরি অ্যাক্সেস করা যাবে না
private balance: number;
constructor(
public holderName: string,
initialBalance: number
) {
this.balance = initialBalance;
}
// Getter method দিয়ে সিকিউরড উপায়ে ব্যালেন্স দেখা যাবে
// getBalance(): number {
// return this.balance;
// }
get getBalance(): number {
return this.balance;
}
// Setter method দিয়ে ব্যালেন্স আপডেট করা যাবে (ভ্যালিডেশনসহ)
// deposit(amount: number): void {
// if (amount > 0) {
// this.balance += amount;
// console.log(` ${amount} BDT added successfully!`);
// }
// }
set deposit(amount: number) {
if (amount > 0) {
this.balance += amount;
console.log(` ${amount} BDT added successfully!`);
}
}
}
const myAccount = new BankAccount('Monir', 1000);
// myAccount.deposit(500);
myAccount.deposit = 500;
// console.log(`Current Balance: ${myAccount.getBalance()} BDT`);
console.log(`Current Balance: ${myAccount.getBalance} BDT`);
// আউটপুট: Current Balance: 1500 BDT

২. Inheritance (ইনহেরিটেন্স - কোড রিইউজবিলিটি)

"একবার লিখবো, বারবার ইউজ করবো!"

ইনহেরিটেন্সের আসল সৌন্দর্য হলো কোড ডুপ্লিকেট করা কমানো। একটি চাইল্ড ক্লাস খুব সহজেই তার প্যারেন্ট ক্লাস থেকে সব কমন প্রপার্টি এবং মেথডগুলো উত্তরাধিকার সূত্রে পেয়ে যায়।

class Person {

constructor(public name: string, public age: number) {}

eat(): void {

console.log(` ${this.name} is having meal.`);

}

}

// Student ক্লাস Person কে ইনহেরিট করছে

class Student extends Person {

constructor(name: string, age: number, public studentId: number) {

super(name, age); // super() দিয়ে প্যারেন্ট ক্লাসের ডেটা ইনিশিয়ালাইজ করা হলো

}

study(): void {

console.log(` ${this.name} is building awesome apps with TypeScript! `);

}

}

const student1 = new Student("Monir", 22, 101);

student1.eat(); // আউটপুট: Monir is having meal.

student1.study(); // আউটপুট: Monir is building awesome apps with TypeScript!

৩. Polymorphism (পলিমরফিজম - বহু রূপ ও ফ্লেক্সিবিলিটি)

"এক নামে বহু রূপ!"

পলিমরফিজম মানে একই ফাংশন বা মেথড বিভিন্ন অবজেক্টে ভিন্ন ভিন্ন আচরণ বা ফলাফল প্রদর্শন করবে (Method Overriding)।

class Animal {

makeSound(): void {

console.log("Animal makes a sound...");

}

}

class Dog extends Animal {

// মেথড ওভাররাইড করা হলো

makeSound(): void {

console.log(" Woof! Woof!");

}

}

class Cat extends Animal {

makeSound(): void {

console.log(" Meow! Meow!");

}

}

// পলিমরফিক ফাংশন

function printAnimalSound(animal: Animal) {

animal.makeSound();

}

printAnimalSound(new Dog()); // আউটপুট: Woof! Woof!

printAnimalSound(new Cat()); // আউটপুট: Meow! Meow!

৪. Abstraction (অ্যাবস্ট্রাকশন - জটিলতা লুকিয়ে রাখা) 👁️‍🗨️

"প্রয়োজনীয় জিনিস দেখাও, অপ্রয়োজনীয় জটিলতা লুকিয়ে রাখো!"

অ্যাবস্ট্রাকশন আমাদের শুধু দরকারি ফিচারগুলো সামনে আনতে সাহায্য করে। টাইপস্ক্রিপ্টে abstract কি-ওয়ার্ড ব্যবহার করে ব্লুপ্রিন্ট তৈরি করা হয়, যার সরাসরি কোনো ইনস্ট্যান্স (অবজেক্ট) তৈরি করা যায় না।

abstract class Vehicle {

// অ্যাবস্ট্রাক্ট মেথড (চাইল্ড ক্লাসে এটি থাকতেই হবে)

abstract startEngine(): void;

move(): void {

console.log(" Vehicle is moving smoothly on the highway...");

}

}

class Car extends Vehicle {

startEngine(): void {

console.log(" Car engine started with a push-button start system!");

}

}

const myCar = new Car();

myCar.startEngine(); // আউটপুট: Car engine started with a push-button start system!

myCar.move(); // আউটপুট: Vehicle is moving smoothly on the highway...
