🚀 TypeScript Generics: পানির মতো সহজ ভাষায় বুঝে নিন! 💧
আমরা যারা জাভাস্ক্রিপ্ট থেকে টাইপস্ক্রিপ্টে আসি, তাদের কাছে Generics নামটা শুনলে কেমন জানি একটা ভয় লাগে, তাই না? মনে হয় অনেক কঠিন কিছু!
আসলে জিনিসটা পানির মতো সহজ। চলুন, একটা বাস্তব উদাহরণ দিয়ে আজকেই আজীবনের জন্য ক্লিয়ার করে ফেলি। 🍔

📌 Generics আসলে কী?
ধরে নিন আপনি একটা জুসের দোকান দিলেন। এখন কাস্টমার আসল, কেউ 🍎 জুস চাচ্ছে, কেউ 🥭 জুস চাচ্ছে। আপনি কি প্রতিটা ফলের জন্য আলাদা আলাদা জুসার মেশিন কিনবেন?
কখনোই না! আপনি একটা কমন "Juicer Machine" রাখবেন, যার ভেতরে যে ফলই দেওয়া হোক না কেন, সে সেটাই জুস বানিয়ে বের করে দেবে।
প্রোগ্রামিংয়ের ভাষায় এই কমন বা রি-ইউজেবল মেশিনটাই হলো Generic (<T>)! অর্থাৎ, আপনি আগে থেকে ফিক্স করে দেবেন না যে ফাংশন বা কম্পোনেন্টে কী টাইপ ডেটা আসবে—এটা ডাইনামিকালি নিজে থেকেই বুঝে নেবে।
💻 কোড দিয়ে বুঝা যাক:
ধরুন, আমরা একটা ফাংশন বানাতে চাচ্ছি যা ইউজারের ইনপুট যা-ই হোক না কেন, তাকে হুবহু সেটাই রিটার্ন করবে।
❌ Generic ছাড়া কোড (যা একটু বিরক্তিকর):
function echoString(arg: string): string { 
      return arg;
 };
function echoNumber(arg: number): number { 
     return arg; 
};
সমস্যা কী? প্রতিটা ডেটা টাইপের জন্য আলাদা আলাদা ফাংশন বানানো লাগছে!
✅ Generics দিয়ে ম্যাজিক (এক তীর দুই পাখি!):
function echo<T>(arg: T): T { 
     return arg; 
} 
// এবার দেখুন কীভাবে কাজ করছে: 
const result1 = echo<string>("Hello TypeScript!"); // টাইপ হলো string 
const result2 = echo<number>(42); // টাইপ হলো number 
// অথবা সংক্ষেপে টাইপ ইনফারেন্স ব্যবহার করে:
const result3 = echo(true); // টাইপ স্বয়ংক্রিয়ভাবে boolean হয়ে যাবে! 
এখানে <T> (যাকে আমরা Type Parameter বলি) হলো ওই জাদুকরী জুসার মেশিন। বাইরে থেকে যে টাইপ পাঠাবেন, T ঠিক সেই রূপ ধারণ করবে!
